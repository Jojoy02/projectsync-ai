# MVP 实现状态

## 已实现

- FastAPI 服务、健康检查和管理 API。
- 飞书事件 URL 校验、可选加密事件解密、消息事件去重和异步处理。
- 飞书应用身份 token 获取、发消息、读取 Docx blocks、读取日历事件的 API 客户端。
- Dify Chatflow API 调用、任务类型 JSON 输出解析和本地无模型降级逻辑。
- 按租户 + 用户隔离的 SQLite 事实、来源、草稿、目标映射、项目归属元数据和审计日志。
- 工作事实去重、业务/项目双关联、个人工作贡献分类、日报/周报草稿生成、草稿自然语言修改。
- 日报/周报独立确认、默认关闭写回、目标块快照比对、冲突保护和写回结果状态。
- 日报/周报定时调度、同一周报日合并消息；可配置时区、日报时间、周报星期与时间。
- 飞书云文档链接登记与增量同步；支持用户指定授权文件夹范围并扫描有限层级的子文件夹；用户可配置日历 ID，日历只作为背景证据。
- 项目归属修改：事实业务/项目重分类，以及当前用户范围内的项目负责人/角色映射。
- Agent Skill、私有 SQLite CLI、Dify DSL 模板、部署说明和自动化测试。

## 需要在目标租户/工作区验证

- Dify DSL 导入兼容性与实际模型供应商配置。不同 Dify 版本可能需要在 UI 中调整节点字段或模型。
- 飞书事件权限、文档应用权限、日历访问权限与回调加密设置。
- 飞书 Docx 文本块 `PATCH` 的实际请求格式和目标租户权限；请先在专用测试文档验证。
- 各租户目标周报的实际结构。当前写回只针对显式映射的普通文本块，不自动定位复杂表格、多段落或多人混排结构。
